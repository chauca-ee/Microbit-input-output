# Micro:bit Projects

A collection of BBC micro:bit projects built with MicroPython.

## Projects

| # | Project | Description |
|---|---------|-------------|
| 1 | Year-100 Calculator | Scrolls a greeting and calculates the year you turn 100 |
| 2 | LED Animations | Custom image frames and walking person animation |
| 3 | Button Handling | Uses buttons A, B, and both to display different messages |
| 4 | Alarm System | Pin-based alarm with flashing LEDs and music |
| 5 | Accelerometer Motion Detector | Detects movement direction across X, Y, Z axes |
| 6 | Compass | Real-time compass needle using the built-in magnetometer |

## Hardware
- BBC micro:bit
- USB-A cable

## Language
MicroPython
